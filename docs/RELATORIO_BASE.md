# Relatório Base - Marketplace de Produtos Artesanais

## Tema escolhido
Marketplace de Produtos Artesanais.

## Problema que o sistema resolve
Pequenos artesãos muitas vezes têm dificuldade para divulgar, organizar e vender seus produtos pela internet. O sistema oferece uma API que permite cadastrar produtos, formas de venda e consultar relatórios básicos.

## Público-alvo
Artesãos, pequenos produtores, empreendedores locais e clientes interessados em produtos feitos à mão.

## Objetivo geral
Desenvolver uma API RESTful segura, escalável e documentada, com autenticação, área pública, área restrita, manipulação de dados via API, conceitos de sistemas distribuídos e versionamento com Git/GitHub.

## Requisitos funcionais
- Cadastro de usuário
- Login com JWT
- CRUD de produtos artesanais
- CRUD de formas de venda
- Listagem de produtos ativos
- Listagem de produtos por usuário
- Relatório resumido via endpoint

## Requisitos não funcionais
- Segurança por autenticação JWT
- Código organizado em apps
- Versionamento com Git/GitHub
- Documentação clara
- API preparada para consumo futuro por web ou mobile
